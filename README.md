# Sistema de Escudo Inspirado no Lanterna Verde

Este projeto inclui dois scripts para Roblox Studio: um LocalScript que detecta a tecla 'E' e dispara um RemoteEvent, e um Script de Servidor que recebe esse RemoteEvent, cria um escudo esférico verde neon e faz o escudo sumir após 4 segundos.

## Install

1. Clone o repositório para sua máquina local.
2. Abra o projeto no Roblox Studio.
3. Cole o arquivo `AtivarAnelLocalScript.server.lua` em `StarterPlayerScripts`.
4. Cole o arquivo `AtivarAnelServerScript.server.lua` em `ServerScriptService`.

## Use

1. Abra o jogo no Roblox Studio.
2. Pressione a tecla 'E' para ativar o escudo.
3. O escudo verde neon aparecerá na frente do jogador e sumirá após 4 segundos.
